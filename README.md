An online clipboard and file-sharing platform — paste text or drop files, get a short share code (or link), and share it with anyone. Inspired by tools like online-clipboard.online.

Live app: tenchi-data.vercel.app

What it does
Share plain text, images, videos, or files instantly via a short, unique share code
Set a custom expiry (1 minute up to 2 days) — clips auto-delete after expiry via a scheduled cleanup job
Upload single or multiple files in one clip
Sign up / log in (email+password or Google OAuth2) to keep a history of your past clips
Retrieve any clip by entering its share code
Light/dark theme with an animated galaxy background and transition effects
